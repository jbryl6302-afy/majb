# 🚑 نظام الإنقاذ الذكي لفائض الدم (Smart Blood Surplus Rescue)

## الفكرة
بدل أن يقتصر النظام على عرض المخزون والتنبيه عند النقص أو قرب انتهاء الصلاحية، أُضيف **محرك ذكي لإعادة توزيع أكياس الدم**
بين بنوك الدم والمستشفيات، بحيث يُنقَص الفائض قبل أن يتحول إلى هدر.

## دورة العمل

```
التنبؤ بالطلب (AI)
        │
        ▼
اكتشاف الفائض تلقائياً  ──►  تحديد الأكياس المعرضة للهدر (تنتهي خلال 21 يوم)
        │
        ▼
البحث عن المنشآت المحتاجة للفصيلة (FacilityNeeds)
        │
        ▼
ترتيب الجهات بدرجة أولوية مركّبة  ──►  تنبيه المسؤول بالاقتراح
        │
        ▼
موافقة المسؤول  ──►  طباعة ورقة تسليم برمز QR  ──►  الشحن  ──►  تأكيد الاستلام
        │
        ▼
تسجيل كامل في TrackingLog + تحديث المخزون + خصم الاحتياج
```

## معادلة الأولوية (100%)

| المعيار | الوزن | التفاصيل |
|---|---|---|
| استعجال احتياج الجهة | 40% | Critical=1.0، Urgent=0.7، Normal=0.4 |
| قرب انتهاء صلاحية الكيس | 25% | ≤3 أيام=1.0، ≤7=0.7، ≤14=0.4، غير ذلك=0.2 |
| حجم الاحتياج | 20% | min(1, الوحدات المطلوبة / 10) |
| قرب المسافة | 15% | 1 / (1 + المسافة/10) |

## اكتشاف الفائض
- الكيس مرشح للإنقاذ إذا: `المخزون المتاح للفصيلة > 1.2 × الطلب المتوقع` **و** `المخزون > 5` **و** `الصلاحية المتبقية ≤ 21 يوم`.
- الطلب المتوقع يأتي من نموذج الذكاء الاصطناعي (`GET /rescue/demand/<month>/<year>` على خدمة Flask)
  وإن كانت الخدمة متوقفة يُستخدم مجموع احتياجات المنشآت كاحتياطي.

## الجداول الجديدة
| الجدول | الوظيفة |
|---|---|
| `Facilities` | بنوك الدم والمستشفيات (الاسم، النوع، المدينة، المسافة بالكم، الهاتف) |
| `FacilityNeeds` | احتياج كل منشأة من كل فصيلة + درجة الاستعجال |
| `Transfers` | اقتراحات وعمليات النقل (الأولوية، الحالة، رمز التسليم QR، الموافقة) |

## حالات عملية النقل
`Suggested` ➜ (موافقة) ➜ `Approved` ➜ (انطلق 🚑) ➜ `InTransit` ➜ (تأكيد الاستلام) ➜ `Completed`
أو `Rejected` / `Cancelled` (تُعاد الأكياس المحجوزة للمخزون).

## التكامل الموجود
- **التتبع بالـ QR**: كل خطوة تُسجَّل في `TrackingLog` (موافقة، شحن، استلام) وتظهر في صفحة تتبع الكيس.
- **التنبيهات**: `api/alerts.php` يضيف تلقائياً تنبيه "نقل إنقاذي مقترح" و"هدر محتمل" للوحة التحكم.
- **الذكاء الاصطناعي**: محرك الإنقاذ يستهلك تنبؤات Random Forest لتحديد الفائض الحقيقي.
- **لوحة التحكم**: كارت "مهددة بالهدر (7 أيام)" + رابط الإنقاذ الذكي في القائمة الجانبية.

## الملفات الجديدة
```

pages/requests/add.php          إنشاء طلب الدم مع التخصيص التلقائي (FIFO + التوافق)
ai_model/predict.py             نقطة النهاية /rescue/demand
```
